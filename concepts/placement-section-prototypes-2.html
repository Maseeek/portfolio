AI Attribution 2.0 Owned the UI overhaul

Next uses its in-house AI, Shield, to suggest product details like age group, material and occasion, which editors used to pick by hand. I owned the overhaul of the editor interface and built the approval rules behind it.

  • Rebuilt the review screen so editors confirm AI suggestions instead of picking every value.
  • Built the rules engine that decides which fields AI may fill and which always need a person, blocking conflicting rules in the UI and API.
  • Turned editor edits into accept, change and reject signals for the Shield team.
  • Pulled shared parts (dropdowns, field cards, AI and rule chips) into a common library.

The project was highlighted by CEO Simon Wolfson in Next's half-year results.
